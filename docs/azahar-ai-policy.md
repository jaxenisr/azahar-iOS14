# Azahar Emulator AI Use Policy

The following document outlines the acceptable and unacceptable uses of AI within the Azahar codebase.

It describes whether or not submissions which were exposed to large language models
(LLMs) such as ChatGPT, Claude, DeepSeek, and similar models would be capable of being
merged in a pull request or otherwise utilized.

- Use of AI to help developers discover or understand problems in the codebase is
  acceptable **under the condition that any discovered issue is independently verified
  by a human**.
- Use of AI to write code snippets of a sufficiently small size that they aren't
  reasonably copyrightable **with disclosure in the PR description** is acceptable.
- Use of AI to write code for submission without disclosure is prohibited.
- Use of AI to write the entirety of a contribution is prohibited.
- Use of AI to rewrite incompatibly-licensed code for submission to Azahar is prohibited.
- Use of AI to autonomously submit pull requests or issues is prohibited.

This policy governs contributions submitted *to the Azahar repository*. This project
consumes Azahar as an unmodified dependency and submits nothing upstream.
